USB Espion — Bad USB

Workshop collaboratif sur le thème « technologie espion » : conception d'un dispositif pédagogique de type Bad USB, d'un firmware ESP et d'un site de supervision pour consulter les données collectées à distance.

  • Python
  • ESP
  • Arduino/C++
  • microSD
  • Impression 3D
  • Express.js
  • HTML/CSS/JS

Document de cadrage (PDF)

Contexte & objectifs

Thème : technologie espion. L'équipe a conçu un Bad USB pédagogique capable de collecter des données sur une machine cible et de les transmettre vers un site web où l'opérateur peut les consulter à distance.

  • Exfiltration locale via script Python déclenché à l'insertion.
  • Support physique : microcontrôleur ESP + carte microSD, boîtier imprimé 3D.
  • Envoi vers un backend et tampon sur microSD si le réseau est indisponible.
  • Tableau de bord web pour visualiser les données récupérées.

Stack technique

  • Collecte : Python
  • Firmware : Arduino/C++ sur ESP (Wi‑Fi)
  • Stockage tampon : microSD
  • API : Node/Express (ingest + auth simple)
  • Dashboard : HTML / CSS / JS
  • Fabrication : impression 3D du boîtier

Réalisations

Organisation

  • Hardware / scripts : préparation du dispositif et des payloads.
  • Backend : API de réception, authentification simple, stockage.
  • Frontend : dashboard, filtres et recherche.
  • Suivi : Kanban (Trello), Git/GitHub, démo finale.

Fonctionnalités clés

  • Déclenchement automatique à l'insertion et collecte ciblée.
  • Buffer microSD puis upload Wi‑Fi via l'ESP.
  • Dashboard : liste des machines, filtres (date, type), aperçu des fichiers.
  • Firmware : gestion Wi‑Fi, microSD, retries réseau et horodatage.
